---- PROBLEMS FOUND --

Problem: search_queries started as None, so adding the first query would crash.
Fixed: it starts as an empty list.

Problem: the Buffer class was written inside the Subgoal class.
Fixed: we moved it out.

Problem: add_record decided inside the loop, so a paper for a real subgoal could be refused.
Fixed: it decides after checking every subgoal.

Problem: add_record had has_record = false, python wants False.
Fixed: we removed the line, it wasn't used.

Problem: is_ready said ready with one subgoal done and two still pending.
Fixed: it now says not ready as soon as one subgoal is pending.

Problem: load_buffer only checked the types, so a paper with no ID could load.
Fixed: every paper goes through add_record again when loading.

Problem: gemini had 3 tries for the subgoals, the report says 1 try and 3 retries.
Fixed: 4 tries.

Problem: gemini flash 3.6 kept reaching the quota limit when i test the first agent. 20 was the quota, even with sleep time added to the execution it wasn't fixed.
Fixed: changed the gemini model to 3.5 flash lite and the first agent finished the search successfully and created the subgoals.
